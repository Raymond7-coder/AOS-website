Compressed-air systems

Air Compression Package

We provide skid-mounted instrument-air and plant-air packages consisting of compressors, dryers, receivers, filtration systems and controls. Each package is engineered and assembled to the client’s specification for continuous and moisture-free compressed-air supply.

Packages are delivered complete, commissioned on-site and sustained in-country through spare-parts support, servicing and reliability upgrades that reduce dependence on overseas technical support and long international lead times.

  • Instrument-air and plant-air compressor packages
  • Air dryers, receivers and filtration systems
  • Integrated controls and package instrumentation
  • Local commissioning, servicing and reliability support
Gas handling

Gas Compression Package

We provide reciprocating, screw and centrifugal gas-compression packages for gas gathering, boosting, gas lift, reinjection and virtual-pipeline applications.

Each package is designed, assembled and commissioned to the relevant API standards. Our in-country service capability and locally available spare-parts support help maintain high equipment availability while reducing maintenance and support lead times.

  • Reciprocating gas-compression packages
  • Screw and centrifugal compressor packages
  • Gas gathering, boosting and gas-lift applications
  • Reinjection and virtual-pipeline duty
Fluid handling

API Pumps

We supply centrifugal, reciprocating and metering pumps built to applicable API standards for process, transfer, injection and chemical-dosing applications.

Every pump is correctly sized to match the operating conditions and required duty. Equipment is supported by OEM-approved in-country overhaul, spare-parts services and reliability upgrades that improve availability and extend operating life.

  • API 610 centrifugal pumps
  • API 674 reciprocating pumps
  • API 675 metering pumps
  • API 676 rotary positive-displacement pumps
Power generation

Gas Generators / Engines

We supply gas-fuelled engines and generator packages for dependable on-site power generation and grid-support applications. Each package is selected and configured to match the site’s fuel-gas quality, operating conditions and load profile.

Packages are delivered as complete systems and sustained through resident servicing, planned overhaul programmes and OEM-approved in-country repairs.

  • Gas-engine generator packages
  • On-site and grid-support power applications
  • Packages matched to fuel-gas quality and site demand
  • Resident servicing and planned overhaul support
